Slide 01 · Technical Architecture

NirogiQ: Technical Foundation

Production-grade architecture designed for sub-second vision inference, multilingual voice, and 100% on-device data sovereignty.

AI VISION ENGINE Google Gemini 3.5 Flash

Multimodal OCR extracts commercial drug name, strength (e.g. 500mg), active salts, and manufacturer with automated fallback.

SERVERLESS BACKEND Node.js on Vercel Edge

Stateless /api/scan-image microservice with input sanitization, payload limits, strict CSP headers, and secure secret handling.

BARCODE SCANNER Client-Side jsQR Engine

Real-time matrix extraction directly on camera canvas streams with zero external API dependencies or latency.

ACCESSIBILITY Web Speech API (TTS)

Native voice synthesis running offline at a calibrated 0.88x speed for English, Hindi (हिंदी), and Punjabi (ਪੰਜਾਬੀ).

PRIVACY FIRST Zero-Knowledge Local Storage

Prescription lists, profiles, and notes remain strictly on the patient's device (localStorage). Zero central database risks.

FRONTEND ARCHITECTURE Progressive Web App (PWA)

Mobile-first standalone web application with zero App Store friction, instant installability, and high contrast styling.

Slide 05 · Monetization

The Business Model & Revenue Streams

A dual B2B & B2C healthcare monetization model built for sustainable growth.

B2B · PRIMARY REVENUE Pharmacy & Telehealth White-Label SDK

Retail pharmacies (e.g. Apollo, Tata 1mg, CVS) license NirogiQ's Gemini vision scanner API for customer refill scanning at $0.02 - $0.05/scan.

B2C · SUBSCRIPTION NirogiQ Family Caregiver Tier ($2.99/mo)

Free for individuals. Premium unlocks remote adherence monitoring for sons/daughters, SMS alerts when parents miss doses, and doctor exports.

B2B · ENTERPRISE Hospital Post-Discharge System ($5k - $20k/yr)

Hospitals issue discharge summaries with NirogiQ QR links to ensure post-operative patients adhere strictly to antibiotic and pain management courses.

DATA · B2B Pharma Packaging Legibility Insights

Aggregated, privacy-compliant readability analytics showing pharmaceutical brands which blister foils suffer high glare and user confusion in the field.
